# Homework 69

Extend the maps app: accumulate places from multiple searches, restore them from localStorage and clear both map and saved data.

Serve the repository with a local HTTP server, for example `python3 -m http.server 5500`, then open `http://localhost:5500/js/69/`.

Enter your own Google Maps browser key and GeoNames username in the setup form. Credentials are not saved. Enable the GeoNames web service for your account. Restrict the Maps key to your localhost origin and the Maps JavaScript API. Live API behavior has not been verified with valid credentials.
