# Homework 76

React weather app: hardcoded ZIP, useEffect fetch, useState, loading/error handling, and a child component displaying weather.

From this folder: `npm ci` (or `npm install` if there is no lock file), then `npm run dev`. Production check: `npm run build`; view with `npm run preview`.

Copy `.env.example` to `.env`, fill in your own OpenWeather key, then restart Vite. Never commit `.env` or a credential-bearing build. VITE_ values are visible in the browser bundle; this prevents repository exposure, not browser visibility. Live weather has not been verified with a valid key.
